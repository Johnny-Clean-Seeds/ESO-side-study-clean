# ESO METHOD AND WORKING ORDER

Status: `ACTIVE_METHOD_SURFACE / SHARED`

Every run uses the house method. Keep the method light enough to move, but strict enough to prevent fog.

## Core Law

`33rd Triple Pass = Walls -> Ceiling -> Roof -> Whole-House Floor Run`

Use `Floor 0` first when the object, branch, or stop condition is blurry.

Best order by situation:

| Situation | Order |
| --- | --- |
| Object/source unknown | `Floor 0 -> Walls -> Ceiling -> Roof -> Whole-House Floor Run` |
| Object known, source route uncertain | `Walls -> Ceiling -> Roof -> Whole-House Floor Run` |
| Several lanes already exist | `Floor 0 -> selected rooms -> Roof -> Whole-House Floor Run` |
| Final synthesis after multiple runs | `Whole-House Floor Run only, with no new claims unless sourced` |

## Shared Rule Cards

| Card | Rule |
| --- | --- |
| `MARKER-OBJECT-LOCK` | Lock location, exact words, dates, symbols, placement, maker, institution, and source quality before meaning. |
| `COVER-MARKER-RIDDLE-SPLIT` | Keep official explanation, object function, symbolic/riddle pressure, and proof status separate. |
| `KNOWN-LOCATION-INDEX-FIRST` | No deep dive starts until the object/location is placed in the index. |
| `DATE-HANDLING` | Dates are event lanes and pressure lanes, not proof of code by themselves. |
| `SOURCE-LADDER-TRIANGULATION` | Prefer primary/object, institutional/history, and comparison lanes when possible. |
| `NAME-VARIANT-STORM` | Search alternate names, spellings, titles, clipped labels, and role words. |
| `PLACE-CHAIN-RECONSTRUCTION` | Build movement/layer chains, not isolated famous dots. |
| `MAP-GRID-EXTRACTION` | Turn maps into tables: base, icon, label, road, trail, region, structure, legend. |
| `CONTRADICTION-HARVEST` | Preserve conflicts instead of smoothing them away. |
| `NEGATIVE-SPACE-SEARCH` | Look for the evidence that should exist if a claim is true. |
| `ADJACENT-QUARANTINE` | Nearby material can compare; it cannot steer without source linkage. |
| `PROOF-STATUS-DOWNGRADE` | No row stays overpromoted. |
| `BATCH-CLOSEOUT` | End with new nodes, upgrades, downgrades, false leads, gaps, and next target. |

## Source Weight

Use this ladder unless the lane says otherwise:

1. Primary artifact, page image, source text, object record.
2. Institutional archive, annual report, directory, official collection record.
3. Museum, university, scholarly site/report.
4. Official civic/design history for civic claims.
5. Named interpretive source for that source's own interpretation only.
6. Video/audio transmission for sequence and editing only.
7. Generic web material.
8. Social media, unsourced symbolic comparisons, sacred-geometry material.

## Exhaustion Rule

A branch is not exhausted until three consecutive searches using different method families produce zero new material.

Example method families:

`archive/finding aid`

`newspaper`

`directory/OCR`

`map/building footprint`

`architecture/public art`

`photo/caption`

`source text/page image`
