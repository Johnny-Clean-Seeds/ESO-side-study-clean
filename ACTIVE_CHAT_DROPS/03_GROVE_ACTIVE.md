# GROVE ACTIVE BRANCH

Status: `ACTIVE_LOAD_SURFACE / GROVE_BRANCH / NOT_FINAL_PROOF`

Active object:

`BOHEMIAN_MARKER_LODGE_NODE_BRANCH`

This branch is a controlled marker/lodge/node investigation into the Bohemian Club city clubhouse, its exterior markers and date-pressure objects, its early address chain, and the later Bohemian Grove route.

It is not a general conspiracy essay, not a people-hunt, not date-code proof, and not a claim that the full Grove map is complete.

## Safe Sentence

The Grove branch is best held as an ordered object-and-place chain: the city clubhouse marker is a confirmed threshold object, the early clubhouse history is a multi-address drift problem, the 1933/1934 marker-building layer is real but not code proof, and the Grove route is a queued second branch that needs map/photo/archive extraction before it can become a full node map.
