## Active decision

The Start Here button should no longer be treated as a black hole, liquid drain, or whole-page physics effect.

The Start Here button is now treated as a doorway.

The visual grammar is:

- the button already looks like a framed door / portal
- the effect should work with that existing shape
- the page should not be swallowed by a giant full-screen effect
- the effect should focus on the button becoming an entrance
- the viewer should understand: "this opens the way"

## Parked effect lanes

Park these lanes unless explicitly revived:

- gravity well
- black hole

- duplicated hero-image background
- full image warp

- canvas-heavy physics effect

Useful material to retain from those lanes:

- no soft paint-shop spotlight

## Door types

### Type A — Key Door

Primary recommended route for Start Here.

Sequence:

1. User clicks Start Here.
2. A small antique key appears from upper-left or left side.
3. The key swirls/floats inward, similar to a game-style magical key.
4. The key touches the Start Here button near a lock point.
5. The Start Here button becomes a real door frame.
6. The interior of the button darkens like an old panel.
7. The door opens inward or cracks open.
8. A narrow hall, stairwell, or passage is visible behind it.
9. The camera/page zooms toward that opening.
10. First test version should reset after animation.
11. Only after approval should it load the next page.

### Type B — False Secret Door

Secondary route, better for an easter egg or hidden pathway.

Sequence:

1. No key.
2. The button or nearby page area behaves like a hidden wall panel.
3. A trigger action occurs, like a pull-the-candlestick secret passage.
4. The panel shifts, cracks, slides, or opens inward.
5. A dark hall/stairwell is visible.
6. Camera/page zooms in.
7. First test version should reset after animation.

## Current route decision

Use Type A for Start Here first.

Reason:

Start Here is a public invitation. A key communicates "opening" clearly. The false-door/candlestick idea is strong, but it reads more like a secret route and should be saved for later unless the user explicitly promotes it.
