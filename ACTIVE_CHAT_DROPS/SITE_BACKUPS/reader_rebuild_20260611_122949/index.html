Map object

The map is a clue object, not a proof object.

The current visual read keeps the red-marker base and the blue-line overlay separate. The red markers look like a modern marker or culture-province layer; the blue lines look like an editorial connection overlay. The older cosmogram model is preserved as a soft suit, but the exact map source remains open until frame order, source image, and capture route are locked.

Allowed

The blue map can be tested as layered symbolic compression if lanes stay separated.

Blocked

The blue lines do not prove ancient planning, Hall authorship, official archaeology, or a 33rd-parallel control model.
