# METHOD HOUSE AND SEARCH CARDS

Status: `ACTIVE_METHOD_SURFACE / CLEAN_START`

## Core Operating Law

Every serious search run uses a `33rd Triple Pass`.

That means:

`Walls -> Ceiling -> Roof -> Whole-House Floor Run`

If the object is still blurry, run `Floor 0` first.

Best order by situation:

| Situation | Best order |
| --- | --- |
| Object/source is unknown | `Floor 0 -> Walls -> Ceiling -> Roof -> Whole-House Floor Run` |
| Object is known, source route uncertain | `Walls -> Ceiling -> Roof -> Whole-House Floor Run` |
| Several lanes already exist | `Floor 0 -> selected room passes -> Roof -> Whole-House Floor Run` |
| Final synthesis after multiple runs | `Whole-House Floor Run only, with no new claims unless sourced` |

## House Levels

`Floor 0 - Front Door`

Lock the active object, question, boundaries, and claim type before searching.

`Walls`

Build the visible body: names, screenshots, source candidates, exact phrases, places, artifacts, and obvious evidence.

`Ceiling`

Find the structure above the visible body: source families, chronology, map layers, symbolic grammar, authority lanes, and dependencies.

`Roof`

Pressure test: false matches, missing custody, weak sources, overclaims, blocked claims, and downgrades.

`Whole-House Floor Run`

Walk every room after the passes. Summarize what the house now knows, what changed, what stayed blocked, and what the next unresolved pressure is.

## Method Cards

| Card | Use |
| --- | --- |
| `33RD-TRIPLE-PASS` | Every serious search gets Walls, Ceiling, Roof, then a Floor Run. |
| `WHOLE-HOUSE-FLOOR-RUN` | Final walk through all rooms after a run or run-cycle. |
| `SOURCE-LADDER-TRIANGULATION` | Prefer primary/source, institution, and comparison lanes when possible. |
| `VIDEO-CUSTODY-GATE` | No video-path promotion without time/order, phrase, image, source, and inference level. |
| `NAME-VARIANT-STORM` | Search all names, spellings, titles, alternate terms, and clipped labels. |
| `PLACE-CHAIN-RECONSTRUCTION` | Treat places as a movement chain or layer chain, not isolated dots. |
| `CULTURE-PROVINCE-MODEL` | Use regions/culture provinces when exact point locks are not justified. |
| `MAP-GRID-EXTRACTION` | Extract visible labels, pins, flags, lines, coordinate hints, and map base style. |
| `SOURCE-WEIGHT-SCALE` | Higher-weight sources control only inside their lane. |
| `OBJECT-SYMBOL-NETWORK-TEST` | Test symbols through object, medium, office, site, and exchange routes. |
| `COSMOGRAM-TEST` | Ask whether a diagram behaves like a world-order model, not a travel route. |
| `PATH-GRAMMAR-TEST` | Test route as ritual road, soul road, sky road, portal path, or axis. |
| `SYMBOL-FAMILY-SPLITTER` | Split similar symbols before merging them. |
| `SAME-WORD-DIFFERENT-SYSTEM` | Same word or image does not mean same institution, lineage, or cause. |
| `EMBLEM-DOUBLE-ENTRY` | Keep Hall's Great Seal interpretation separate from official U.S. history. |
| `CENTER-STACK-LEDGER` | Track object, site, landscape, national emblem, and theology centers separately. |
| `NEGATIVE-SPACE-SEARCH` | Search for what should exist if a claim is true but is missing. |
| `ADJACENT-QUARANTINE` | Keep attractive nearby material from steering the run. |
| `CONTRADICTION-HARVEST` | Preserve conflicts instead of smoothing them away. |
| `PROOF-STATUS-DOWNGRADE` | Downgrade exact locks, lineages, and causes when custody is thin. |

## Source-Weight Scale

Use this order unless the lane itself says otherwise:

1. Primary artifact/catalog/source text.
2. Archaeology/site report.
3. Museum/university source.
4. Official U.S. source for Great Seal history.
5. Hall source for Hall interpretation.
6. Cooper transmission for audio/order.
7. Mercy Hunter visual argument for video editing.
8. Generic web/source-family material.
9. Social media or sacred-geometry material.
