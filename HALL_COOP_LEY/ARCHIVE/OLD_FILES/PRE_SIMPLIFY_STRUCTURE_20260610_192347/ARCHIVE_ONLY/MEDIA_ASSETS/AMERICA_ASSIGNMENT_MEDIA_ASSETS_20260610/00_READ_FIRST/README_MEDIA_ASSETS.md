This packet is a clean place to hold media assets for the branch: screenshots, video frames, map images, artifact images, PDFs, audio clips, and transcripts.

No actual local media binaries were found in `/mnt/data` at build time. That means there were no local `.png`, `.jpg`, `.pdf`, `.mp4`, `.mp3`, `.wav`, etc. files to send as media assets.

The generated project packets contain Markdown/text/JSON/ZIP materials, not actual image/video/PDF/audio binaries.

## What is included instead

This packet includes:

1. a no-local-media receipt;
2. an external media/source-route ledger extracted from the research stack;

## How a new agent should use this

Do not treat external URLs as downloaded assets.
Do not claim a frame, artifact, or map is locked until the actual file or page is opened and source-checked.
Use the drop-target folders to keep future media from mixing with active Markdown handoff files.
