## Bridge Court throttle

Bridge Court runs only when:

1. a fork directly blocks the next path’s core question;
2. two next paths are competing;
3. the user asks whether a path is ready;
4. a path board has completed a full cycle and needs comparison;
5. a contradiction changes path order.

Bridge Court is a gate, not a tunnel.

## Fork-readiness law

A fork does not automatically block the next path. A fork blocks only the claim-type it touches.

Separate:

`PATH-OPENING READINESS`

from:

`PROOF / LINEAGE / IDENTITY READINESS`

- source-text test;
- editor-sequence test;
- symbolic-grammar test;
- archaeological-field test;
- mechanism test;
- lineage test;
- identity test;
- causation test.

Lineage, identity, and causation require hardest proof.
