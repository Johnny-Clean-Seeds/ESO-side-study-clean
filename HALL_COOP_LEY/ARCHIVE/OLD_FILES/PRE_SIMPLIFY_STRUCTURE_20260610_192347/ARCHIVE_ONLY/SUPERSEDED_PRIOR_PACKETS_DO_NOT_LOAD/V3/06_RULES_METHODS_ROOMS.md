# RULES, METHODS, ROOMS — V3

Status: `OPERATING_RULES / LOAD_BEFORE_ACTING`

## 1. Response mode rule

Every future response must choose one mode:

`RESEARCH RUN`
`FREEZE`
`BRIDGE COURT`
`HANDOFF`
`REVIEW`

Action commands such as `next`, `nxt`, `go`, `run`, `begin`, `continue`, and `do it` default to `RESEARCH RUN`.

## 2. Action-first rule

When the user asks to move, the agent moves. Do not turn action commands into recap, readiness gate, Bridge Court, method invention, or reload of the whole branch.

## 3. Stale packet override

Priority order:

1. Latest direct user instruction.
2. Latest accepted freeze/ruling in current conversation.
3. Latest patch card.
4. Latest handoff.
5. Older handoff or method file.
6. Earlier exploratory notes.

## 4. Fork-readiness rule

A fork does not automatically block the next path. It blocks only the claim-type it actually touches.

Separate:

`PATH-OPENING READINESS`

from

`PROOF / LINEAGE / IDENTITY READINESS`

Use `READY_LIMITED_SCOPE` when a path may run as source-text, symbolic-grammar, archaeology-field, editor-sequence, or mechanism test while lineage/identity/causation remains blocked.

## 5. Fork-path-cycle rule

When a fork appears:

1. Pick one path or one justified combo.
2. Run until hard source, contradiction, no-new-material point, or next fork.
3. Freeze.
4. Record what was found, not proven, downgraded, blocked, and next.
5. Only after fair passes come full circle and compare.

## 6. No watery runs / no gap runs

Every research run must include:

`source route`
`claim boundary`
`gap ledger`
`downgrade ledger`
`blocked claims`
`next unresolved pressure`
`method use`

## 7. Video custody gate

Before promoting a video-map path, record:

`time/order → spoken phrase → on-screen image → identifiable image/source → Hall passage if any → archaeology control if any → inference level`

Current-video frame capture is locally exhausted. Missing visual links require outside source recovery, related part, original page, image match, transcript, or audio match.

## 8. Source ladder

Separate Hall, Cooper, Mercy Hunter, archaeology, official U.S. history, Bible frame, and inference.

Do not collapse voices.

## 9. Source-weight scale

Highest control:

`primary artifact/catalog` > `archaeology/site report` > `museum/university source` > `Hall symbolic synthesis` > `Cooper transmission` > `Mercy Hunter visual argument` > `generic web/source-family` > `social media/sacred geometry`

## 10. Rooms

`Front Door` — active object and current question.

`Proof Room` — sourced vs attractive.

`Video Custody Room` — exact sequence, phrase, image, inference level.

`Map Room` — regions, overlays, culture provinces, geometry.

`Symbol Room` — serpent, bird, thunderbird, cross, circle, phoenix, eagle.

`Object Room` — shell cups, copper plates, disks, regalia, artifact catalogs.

`Word Room` — orenda, manito, totem, daemon, path, portal, road, axis, principalities, powers.

`Archaeology Room` — SECC, Mississippian, Fort Ancient, Oneota, Caddoan, Plaquemine, Cahokia, Moundville, Spiro.

`Indigenous Control Room` — prevents Hall/Mercy/Cooper from overriding Indigenous or archaeological specificity.

`Crime Scene` — source contamination, false promotion, forced paths.

`Creative Room` — hypotheses only, with labels.

`Final Judge` — promote, downgrade, freeze, park, quarantine, kill.

`Soft Suit` — anti-overclaim and pattern-forcing brake.
