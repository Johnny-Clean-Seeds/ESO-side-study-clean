## Rule Cards

### RULE CARD 001 - Marker Object Lock
When addressing a plaque, motto, emblem, date set, building, gate, shrine, statue, or threshold object, lock the physical object first. Object card fields: location, exact visible words, symbols, dates, material if known, placement, maker if known, institution, first documented appearance, current photo/source, and source quality. Do not jump straight to meaning; first answer what is physically there.

### RULE CARD 002 - Cover / Marker / Riddle Split
Every object gets four separate readings: cover reading, marker reading, riddle/code reading, and proof status. Official meaning is allowed as one lane, but it is not allowed to become the whole object.

### RULE CARD 003 - Known Location Index Before Batches
No deep dive starts until the object is placed into the master index. Labels: CONFIRMED_OBJECT, CONFIRMED_FAMILY, CANDIDATE, ADJACENT_ONLY, REJECTED / WRONG_LANE.

### RULE CARD 004 - Date Handling
Dates are not random decoration and not secret code by default. Each date gets three lanes: documented event, placement function, and pattern pressure. A date pattern strengthens only if it repeats across locations, documents, ceremonies, markers, or rules.

### RULE CARD 005 - 33rd Batch Form
Each batch runs Walls, Ceiling, Roof. Round 1 builds the visible object/location body. Round 2 uses Round 1 as source and tests structure, chronology, names, and evidence quality. Round 3 uses Round 2 as source and pressures false readings, missing sources, date traps, symbol traps, and unsupported leaps.

### RULE CARD 006 - Branch Exhaustion Rule
Do not stop a branch because one search slows down. A branch is not exhausted until three consecutive searches, each using a different method family, produce zero new material. New material includes new node, address clue, marker, wording, source path, date conflict, upgrade, downgrade, contradiction, rejected false lead, or better proof route.

### RULE CARD 007 - Results-First Reply Rule
After methods and rules are set, do not keep restating what needs to be done. Report what was searched/tested, what changed, and whether the branch is active or exhausted.

## Method Cards

### METHOD 001 - Source-Ladder Triangulation
Every node should have up to three source lanes when possible: primary/object source; institutional/history source; reception/comparison source. One source does not make a promotion by itself.

### METHOD 002 - Name-Variant Storm
Search each node under all likely names: Bohemian Club, The Bohemians, Jolly Corks, High Jinks, Midsummer Jinks, Grove Play, Nest of the Owl, club-house, clubhouse, chalet, lodge, camp, circle, shrine, lake, owl, spider, weaving spiders.

### METHOD 003 - Place-Chain Reconstruction
Build the index as a movement chain, not a list of famous places: home meeting -> rented room -> formal club rooms -> early city headquarters -> outdoor route -> Grove predecessor -> purchased Grove land -> first Grove building/lodge -> later city clubhouse -> marker families -> internal Grove nodes -> camps.

### METHOD 004 - Address Drift Sweep
Search every known address separately and then adjacent blocks. Locations are not locked until exact, approximate, renamed, demolished, rebuilt, or drifted status is identified.

### METHOD 005 - Archive Box-to-Object Chase
When an archive says it has programs, menus, posters, scripts, maps, scrapbooks, or photographs, create extraction targets instead of stopping at the collection title.

### METHOD 006 - Photo-Caption Mining
Treat photographs as source objects: caption, date, location, visible structures, visible text, visible symbols, seating pattern, gate/threshold placement, camp name, photographer, and what the image proves.

### METHOD 007 - Map Grid Extraction
Turn maps into tables: roads, trails, camps, buildings, circles, stages, water features, named groves, entrances, boundaries, and legends.

### METHOD 008 - Date Pressure Crosswalk
For each date, capture documented event, object placement, repeated appearances, contradiction pressure, and symbolic/riddle pressure.

### METHOD 009 - Cover / Marker / Riddle Split
Each object receives cover reading, marker function, riddle pressure, and proof status. The official reading is not the full reading by default.

### METHOD 010 - Contradiction Harvest
When a source/object creates tension, keep the contradiction. Do not smooth it away. Example: a networking institution placing a motto against web-weaving.

### METHOD 011 - Negative-Space Search
Search for what should exist but is missing: first meeting address, exact Jolly Corks rooms, plaque dedication notice, building permits, cornerstone records, photos of old clubhouses, and missing source trails.

### METHOD 012 - Adjacent Quarantine
Similarity is not lineage. Masons, Odd Fellows, Elks, owl symbolism, Shakespeare, mystery schools, and fraternal architecture can compare but not prove without source linkage.

### METHOD 013 - Insider-Word Sweep
Search repeated house language across programs, menus, maps, speeches, plaques, room names, scripts, and notices.

### METHOD 014 - Event-to-Place Conversion
Treat events as location leads. Dinners, plays, Jinks, encampments, concerts, exhibitions, and banquets may identify rooms, stages, groves, circles, camps, or marker locations.

### METHOD 015 - Demolition / Fire / Rebuild Gate
Every city-club location must be checked against the 1906 fire/earthquake, destruction, emergency quarters, relocation, rebuilding, and address changes.

### METHOD 016 - Membership-Map Separation
Membership records may explain institutional movement and access rules, but they are not the index itself and should not become a people-hunt.

### METHOD 017 - Object Family Builder
For each physical node, search plaque, door, gate, owl, inscription, cornerstone, stage backdrop, camp sign, menu, program, seal, medal, letterhead, map, ticket, banner, dedication stone.

### METHOD 018 - Proof-Status Downgrade Rule
No row stays overpromoted. Use LOCKED_OBJECT, LOCKED_SOURCE, LIKELY_NODE, CANDIDATE_NODE, ADJACENT_ONLY, REJECTED, and WATCH labels.

### METHOD 019 - Round-Robin Search Rotation
Do not search the same way twice in a row. Rotate archive, newspaper, map, image/caption, architecture, catalog, name-variant, date, and contradiction methods.

### METHOD 020 - Batch Closeout Card
Every batch closes with new nodes, upgraded nodes, downgraded nodes, unresolved address questions, date pressure notes, symbol/riddle notes, best sources found, weak sources rejected, and branch status.

## Status Labels
| Label | Meaning |
| --- | --- |
| LOCKED_OBJECT | Exact object/place is supported by reliable source evidence. |
| LOCKED_SOURCE | The source exists and is useful, but objects inside still need extraction. |
| CONFIRMED_OBJECT | Object/location is documented, though finer details may still need inspection. |
| CONFIRMED_FAMILY | The location/family is documented; specific marker/object details need inspection. |
| STRONG_DIRECTORY_NODE | A city directory or phone directory strongly supports the address/location. |
| STRONG_TEMP_NODE | Temporary location is backed by strong source evidence. |
| STRONG_FIRE_NODE | Fire/damage/displacement source evidence strongly supports the node. |
| LIKELY_NODE | Good evidence exists but an exact detail is incomplete. |
| CANDIDATE_NODE | Plausible but needs confirmation. |
| WATCH | Conflict, date pressure, address drift, transition overlap, or contradiction is active. |
| ADJACENT_ONLY | Useful comparison, not same-family proof. |
| REJECTED_FALSE_LEAD_UNTIL_REPROVEN | A false lead was identified and should not be used unless later evidence revives it. |
