# METHOD HOUSE AND SEARCH CARDS

Status: `ACTIVE_METHOD_SURFACE / GROVE_BRANCH`

## Core Operating Law

Every serious search run uses a `33rd Triple Pass`.

That means:

`Walls -> Ceiling -> Roof -> Whole-House Floor Run`

Use `Floor 0` first when the active object or boundary is blurry.

## House Levels

`Floor 0 - Front Door`

Lock the active object, branch, claim type, source family, and stop condition.

`Walls`

Build the visible object/location body: names, dates, addresses, visible markers, exact wording, images, source candidates, and known conflicts.

`Ceiling`

Test the structure: chronology, address drift, source quality, event-to-place links, institution rules, marker families, map layers, and branch order.

`Roof`

Pressure the run: false readings, date traps, source mixing, OCR errors, missing page images, unsupported symbolic leaps, and overpromoted claims.

`Whole-House Floor Run`

Walk every active room after the pass. Record what changed, what stayed blocked, what was downgraded, and the next exact proof move.

## Rooms

Use one active room at a time.

| Room | Use |
| --- | --- |

| Map Room | Sanborn maps, Grove cartographs, roads, trails, camps, stages, boundaries. |

| Soft Suit | Allows suspicion without premature claims. |
| Final Judge | Promote, freeze, downgrade, park, quarantine, kill, or continue. |

## Rule Cards

| Card | Rule |
| --- | --- |
| `MARKER-OBJECT-LOCK` | Lock the physical object before meaning: location, exact words, dates, symbols, placement, maker, institution, source quality. |
| `COVER-MARKER-RIDDLE-SPLIT` | Every object has cover reading, marker reading, riddle pressure, and proof status. |
| `KNOWN-LOCATION-INDEX-FIRST` | No deep dive starts until the object is placed in the master index. |
| `DATE-HANDLING` | Dates are event lanes and pressure lanes, not proof of code by themselves. |
| `33RD-TRIPLE-PASS` | Each batch runs Walls, Ceiling, Roof, then a Whole-House Floor Run. |
| `BRANCH-EXHAUSTION` | A branch is not exhausted until three consecutive searches using different method families produce zero new material. |
| `RESULTS-FIRST` | Report what was tested, what changed, and whether the branch is active or exhausted. |
